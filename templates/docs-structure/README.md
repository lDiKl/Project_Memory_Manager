# Project Memory

This folder is managed by **Project Memory Manager (PMM)**.

## Structure

| Folder | Purpose |
|---|---|
| `project/` | Vision, architecture, roadmap. |
| `modules/` | Per-module documentation. |
| `tasks/` | Active and completed tasks. |
| `bugs/` | Bug reports and fix history. |
| `decisions/` | Architecture Decision Records. |
| `llm/` | Rules and prompts for AI assistants. |
| `knowledge/` | Stack, patterns, conventions. |

## Common commands

```bash
pmem scan           # detect modules
pmem task create    # new task
pmem bug create     # new bug
pmem adr create     # new architecture decision
pmem check          # check docs are up to date
```
